# GitHub Trending CLI

A command-line interface (CLI) tool built to fetch and display trending repositories from GitHub.

## Project Link
https://roadmap.sh/projects/github-trending-cli

## Prerequisites
- Python 3.x
- `requests` library

## How to Run
1. Clone the repository:
   `git clone https://github.com/SanchitSingh382/github-trending-cli.git`
2. Install dependencies:
   `pip install requests`
3. Run the tool:
   - General trending: `python main.py`
   - Filter by language: `python main.py -l python`
